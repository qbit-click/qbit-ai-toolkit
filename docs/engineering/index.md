# Engineering Reference

This section contains the technical contracts that define how Qbit AI Toolkit is structured, versioned, secured, and consumed. It is intended for maintainers and integrators rather than as a user tutorial.

## Topics

- repository architecture and ownership boundaries;
- asset and catalog contracts;
- naming and repository conventions;
- security and trust boundaries;
- versioning and compatibility rules.

Operational how-to guidance remains under the relevant product domain. For example, Codex AI Tooling operations live under **AI Tools**, while reusable skill design lives under **Agents & Skills**.
