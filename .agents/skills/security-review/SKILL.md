# Security review

Review affected trust boundaries and repository evidence for filesystem scope,
path validation, command execution, archive extraction, remote downloads, secrets,
Docker isolation, release integrity, state ownership, and Force, backup, or
uninstall behavior.

Separate confirmed findings from unverified concerns. For every finding, report
severity, evidence, the affected boundary, exploitability assumptions, and a
concrete remediation. Do not claim a vulnerability without evidence and do not add
a generic security scanner.
