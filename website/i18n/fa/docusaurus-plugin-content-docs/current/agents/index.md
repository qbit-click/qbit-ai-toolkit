# ایجنت‌ها و اسکیل‌ها

این بخش رفتار reusable ایجنت را پوشش می‌دهد: طراحی skill، سازمان‌دهی skillهای آماده و policyهایی که رفتار agent را در repositoryها و ابزارهای مختلف محدود می‌کنند.

## Skill در برابر Tool

**Tool** یک capability مانند خواندن repository، جست‌وجوی مستندات یا اجرای validation را در اختیار agent قرار می‌دهد. **Skill** workflow قابل استفاده مجددی است که مشخص می‌کند چه زمانی و چگونه از capabilityها برای یک کلاس مشخص از task استفاده شود.

## چه چیزهایی اینجا قرار می‌گیرند؟

- conventionهای طراحی و نگارش skill؛
- skillهای آماده reusable؛
- policy و constraintهای agent؛
- روش تست و versioning رفتار reusable agent.

Assetهای skill زیر `agent-assets/skills/` و policyها زیر `agent-assets/policies/` قرار می‌گیرند. setup ابزار زیر **ابزارهای AI** یا **MCP** باقی می‌ماند.
