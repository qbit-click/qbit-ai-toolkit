# مرجع مهندسی

این بخش قراردادهای فنی‌ای را نگه می‌دارد که ساختار، versioning، security و نحوه مصرف Qbit AI Toolkit را تعریف می‌کنند. مخاطب اصلی آن maintainerها و integratorها هستند، نه کاربری که فقط به یک tutorial عملی نیاز دارد.

## موضوعات

- معماری repository و ownership boundaryها؛
- قرارداد asset و catalog؛
- naming و conventionهای repository؛
- security و trust boundaryها؛
- versioning و قواعد compatibility.

راهنمای عملیاتی هر ابزار در domain خودش باقی می‌ماند؛ مثلاً عملیات Codex AI Tooling زیر **ابزارهای AI** و طراحی skill reusable زیر **ایجنت‌ها و اسکیل‌ها** قرار دارد.
